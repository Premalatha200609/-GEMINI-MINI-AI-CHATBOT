# Gemini Mini AI Chatbot

Gemini Mini AI Chatbot is a simple and interactive AI chatbot that uses the **Google Gemini API** to understand user queries and generate intelligent responses.

## About the Project

This project is designed to demonstrate how an AI-powered chatbot can be developed using the Gemini API. Users can enter their questions or messages, and the chatbot processes the input and provides relevant responses.

The project focuses on creating a simple, user-friendly interface while integrating AI capabilities for real-time conversation.

## Features

* Interactive chatbot interface
* AI-generated responses using Gemini API
* Real-time conversation
* Simple and user-friendly design
* Handles different types of user queries
* Easy to run and extend

## Technologies Used

* **Python**
* **Google Gemini API**
* **HTML**
* **CSS**
* **JavaScript**

## How It Works

1. The user enters a question or message in the chatbot.
2. The application sends the user's input to the Gemini API.
3. Gemini processes the input using its AI capabilities.
4. The generated response is received by the application.
5. The chatbot displays the response to the user.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Premalatha200609/-GEMINI-MINI-AI-CHATBOT.git
```

### 2. Open the project folder

```bash
cd -GEMINI-MINI-AI-CHATBOT
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the Gemini API Key

Create a Gemini API key and configure it securely in your project.

**Do not upload your API key directly to GitHub.**

For example, use an environment variable:

```text
GEMINI_API_KEY=your_api_key_here
```

### 5. Run the application

```bash
python app.py
```

Then open the local URL shown in the terminal.
